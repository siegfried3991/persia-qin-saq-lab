# Persia and Qin SAQ Lab

Mobile-friendly history revision notes and guided sentence-choice SAQ practice.

[Open the study guide on GitHub Pages](https://siegfried3991.github.io/persia-qin-saq-lab/)

## Run locally

No build or dependencies required. Serve this directory over HTTP, for example `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Files

- `index.html`: page shell
- `style.css`: responsive layout, including phone lesson selector and large tap targets
- `data.js`: 9 short notes and 8 SAQ builders with 24 first-answer choices
- `app.js`: immediate feedback, answer assembly, saved browser progress, mistake review, export and reset

## Sources and scope

Persia follows the class worksheet headings: Cyrus, Babylon, Darius, satrapies and the Royal Road. Qin practice uses the teacher’s 3 November 2026 exemplar PDF. Cyrus/Babylon museum background is clearly marked as supplementary. Sources are linked in the guide. No full school documents, student responses, scores, passwords or hosting credentials are included.

The guide does not claim to grade an unavailable student Qin response. Its practice prompts are newly written rather than presented as the original worksheet questions. TEA is a classroom writing scaffold, not an official AP sentence-count rule.

## Privacy

Progress is saved only in the current browser. This standalone guide has no student accounts and does not sync with Teams or Quest Campus. The repository and GitHub Pages website are public. Practice choices and progress are not uploaded to GitHub. The earlier ChatGPT Sites copy is separate.
